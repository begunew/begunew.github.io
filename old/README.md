# Family Therapy Center — Static HTML/CSS/JS

Simple GitHub Pages-ready prototype for the Family Therapy Center at Lee University.

Files:
- index.html
- style.css
- script.js

GitHub Pages supports JavaScript in static sites. This project only uses a tiny JS file for the mobile navigation; there is no backend, database, or server-side code.

Before publication, verify all current clinical/legal wording, rates, contact information, and institutional branding with the department.
